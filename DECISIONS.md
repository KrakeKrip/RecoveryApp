# Журнал технических решений

## 2026-10-18 — потоковые находки и независимые quick workers (TASK-017)

fls stdout читается через PTY, чтобы включить line buffering без патча или
пересборки TSK. Только stdout: stdin Security/сырого дескриптора неизменён,
stderr дренируется отдельно. Формирование кандидатов остаётся в общем Core.
Для сохранения во время поиска используется другой runner/process. Физические
workers делят только права авторизации; новый helper открывает независимый
read-only FD и повторяет прежние проверки. Один save batch одновременно,
без автоматического добавления поздних находок/повторного сохранения готовых.
CLI JSON не меняется; реальный физический параллельный режим не объявляется
проверенным по синтетике. Владелец разрешил main и новый Latest.

## 2026-10-18 — явный путь навигации вместо optional-item presentation

После сообщения и видео с M2 / macOS 14.5 заменён общий переход главного
экрана: `NavigationStack(path:)` + `navigationDestination(for:)`. Выбор и путь
не хранятся независимо: путь — проекция `selectedFeature`, native Back
очищает тот же выбор. Добавлена прямоугольная зона нажатия всей карточки.
RecoveryCore, доступ к дискам и сторонние инструменты не меняются.
Это исправление предполагаемой причины; локальная GUI-приёмка не заменяет
повторный тест на 14.5. По прямому запросу владельца исправление отправляется
в main, пакет v0.8.1-lab.2 публикуется как Latest с этим ограничением.
Версия приложения 0.8.1 (13) не повышается; пакет отличается тегом и именами.

## 2026-10-06 — provenance через контрольную сборку (TASK-016)

Существующие версии инструментов не обновляются. Рабочие бинарники заменяются
проверенными сборками из локальных распространяемых архивов и идентифицированных
патчей; фактическая конфигурация FFmpeg и цепочка хешей сохраняются как evidence.
Совпадение со старым бинарником не является критерием приёмки: новая сборка
доказывает происхождение новых файлов, но не ретроспективно старых релизов.
Двухсборочная побайтная воспроизводимость не объявляется без проверки.
Реальные носители/авторизация и юридическое одобрение распространения вне задачи.

## 2026-10-06 — отложить проверку содержимого результатов

По прямому решению пользователя TASK-013 и TASK-014 отложены: отдельная проверка фото/контейнера видео сейчас усложняет продукт, а её ограниченный результат может создавать ложную уверенность. Пользователь может открывать сохранённые файлы самостоятельно; существующая сверка размеров и предупреждения остаются. Предыдущее предложение ниже не является разрешением на реализацию. Возобновление — только новым заданием координатора. Следующие приоритеты: установка на другом Mac, лицензионная приёмка и расширенные тесты существующего восстановления. Сеть/телеметрия/автообновления остаются отдельным будущим этапом.

## 2026-10-06 — ограниченная проверка результатов, CLI-first

TASK-013 добавляет отдельный read-only сервис в RecoveryCore и явную CLI-команду; интеграция GUI — TASK-014. Проверка не запускается автоматически и не меняет статусы сверки размера/успех восстановления. JPEG/PNG проверяются системными ImageIO/CoreGraphics (это платформенные frameworks, не новые внешние зависимости). MOV/MP4 на первом этапе проверяются ограниченным локальным разбором структуры контейнера: без сетевого доступа, воспроизведения, декодирования всех кадров и внешних инструментов. Статус читаемого контейнера не означает исправное видео. Неподдерживаемые/слишком ресурсоёмкие случаи — «Не проверен», не «Повреждён». Без нового ffprobe/FFmpeg и без изменений стороннего dmgbuild в этих задачах.

## 2026-09-18 — CLI-first разработка

Сначала создаётся тестируемый CLI backend, затем SwiftUI переводится на тот же
`RecoveryCore`. Это уменьшает число GUI-запусков и делает работу проверяемой.

## 2026-09-18 — Git-задача как единица работы

Каждая задача выполняется в отдельной ветке GLM и заканчивается отчётом и
коммитом реализации. Исправления по ревью добавляются отдельными коммитами без
переписывания истории. GLM передаёт полный хеш последнего коммита; Codex
проверяет его и после принятия записывает хеш в `TASKS.md`. Сам отчёт не может
содержать хеш коммита, в который он включён.

## 2026-09-18 — Без внешней библиотеки аргументов

Начальный CLI использует Foundation и небольшой собственный разбор аргументов.
Новые зависимости не добавляются без отдельного решения.

## 2026-09-18 — JSON для автоматизации

CLI имеет стабильный JSON-режим. Длительные операции позже используют JSONL.
Обычный текст остаётся русским.

## Ранее — отдельные CLI Sleuth Kit

`mmls`, `fls` и `icat` запускаются как независимые процессы и не линкуются с
GPL-кодом RecoveryApp из-за лицензионного риска CPL/IPL.

## Ранее — физический источник только для чтения

Доступ выдаётся через Authorization Services и `authopen`. Native helper
проверяет режим дескриптора, размер устройства и запрет результата на источнике.
