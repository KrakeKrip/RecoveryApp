# RecoveryApp — описание продукта

## Назначение

RecoveryApp — бесплатное некоммерческое приложение для Apple Silicon Mac,
которое помогает обычному пользователю восстановить удалённые фото и видео с
флешек, карт памяти и внешних дисков, а также исправить повреждённое видео по
исправному примеру с того же устройства.

Программа не гарантирует восстановление. Результат зависит от перезаписи данных,
фрагментации, файловой системы и степени повреждения.

## Пользовательские сценарии

- Быстрый поиск FAT32/exFAT через `mmls`, `fls` и `icat` с попыткой сохранить
  имена файлов.
- Глубокий поиск JPEG, PNG и MOV/MP4 через PhotoRec без исходных имён и папок.
- Исправление видео встроенным `untrunc` по исправному примеру.
- CLI для автоматических тестов и диагностики через общий `RecoveryCore`.

## Неприкосновенные требования безопасности

- Источник открывается только для чтения.
- Результат никогда не записывается на исходный физический диск.
- Перед операцией повторно проверяются устройство и его размер.
- Приложение не получает и не хранит пароль.
- Отмена завершает всю группу дочерних процессов.
- Содержимое файлов не передаётся по сети.
- ETA не показывается без достоверных данных.

## Текущие границы релиза

- Версия 0.8.1, build 13 — лабораторная.
- Нет Developer ID, hardened runtime и нотариализации.
