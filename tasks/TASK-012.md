## Реализация

1. Общая чистая фильтрация в RecoveryCore над `DeletedFileCandidate`, без SwiftUI, чтения содержимого, процессов и авторизации. GUI только хранит запрос и отображает результат общей функции. Существующие CLI-контракты не менять; фильтры CLI в этой задаче не нужны.
2. Типы: «Все», «Фото», «Видео», «Документы», «Другое». Категория — только подсказка по расширению, не доказательство содержимого. Регистр расширения не важен. Зафиксировать таблицу расширений в коде и ARCHITECTURE.md: фото jpg/jpeg/png/heic/heif/tif/tiff/gif/bmp/webp; видео mp4/mov/m4v/avi/mkv/mts/m2ts/3gp/webm; документы pdf/txt/rtf/doc/docx/xls/xlsx/ppt/pptx/odt/ods/csv. Без расширения и остальные — «Другое».
3. Поле «Поиск по имени» — нечувствительное к регистру вхождение в displayName; пробелы по краям запроса убрать. Не искать по содержимому. Поддержать кириллицу.
4. Размер — необязательные минимальный/максимальный пороги в МиБ (1 МиБ = 1 048 576 байт), целые неотрицательные числа, включительные границы. Неизвестный размер показывать явно; без размерных ограничений не исключать. При активном пороге неизвестные исключить с коротким пояснением рядом с фильтром. Отрицательные, нечисловые, переполнение и минимум больше максимума — понятная локальная ошибка; не применять ошибочный запрос и блокировать восстановление до исправления/сброса. Пустые поля отключают ограничения.
5. Тип, имя и размер объединяются по AND. При изменении фильтра исходный массив не меняется, порядок найденных записей сохраняется. Никакого повторного скана.
6. Сохранить текущий спокойный дизайн. Компактные тип и поиск рядом с таблицей; размер — в раскрываемом блоке «Размер». «Сбросить фильтры» и счётчик «Показано X из Y». Не показывать панель до завершённого скана, не добавлять фильтры на главную или экран видео.
7. Безопасная семантика выбора: после изменения фильтров оставить выбранными только видимые записи (пересечение ID), «Выбрать все» выбирает только видимые. Восстановление получает только видимые выбранные кандидаты; нельзя восстанавливать скрытое из старого selection. Количество выбранных и состояние кнопки должны совпадать. При смене источника/новом скане сбросить фильтры и selection; не ослаблять существующую проверку идентичности скана. Во время операции фильтры и выбор недоступны.
8. Различать «Удалённые файлы не найдены» и «По заданным фильтрам ничего не найдено»; во втором случае доступен сброс. Смена фильтров не меняет восстановленные файлы и карточку результата. Проверить, не скрывает ли текущая result-фаза панель: фильтрация нужна в фазе выбора находок, не требует нового браузера сохранённых результатов.
