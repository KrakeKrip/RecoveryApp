# Исправление переходов главного экрана на macOS 14.5

Исполнитель Codex. Ветка `codex/fix-sonoma-home-navigation`.
Основание: пользовательское видео — установленная 0.8.1 (13) на M2 / macOS
14.5 открывается, карточка нажимается, но переход не происходит.
Причина внутри SwiftUI runtime не доказана; применить узкое исправление
маршрутизации, не объявлять совместимость с 14.5 проверенной без Mac пользователя.

## Объём

- Явный NavigationStack path и value destination вместо optional-item destination.
- Один источник состояния выбранного раздела и возврата; кликабельна вся карточка.
- Доменный регресс: оба маршрута, возврат, повторный вход, тестовые точки входа.
- Свежая release .app, подпись, GUI: обе карточки, native Back, повторные переходы,
  попадания по тексту и пустой области. Не использовать тестовый автопереход
  вместо реального нажатия при основной GUI-приёмке.
- Отдельный ZIP приложения и соответствующий source ZIP для передачи другу;
  не перезаписывать старые релизы. Версию/build не менять.
- Краткий отчёт с точными проверками и непроверенными сценариями.

RecoveryCore, CLI, helper, инструменты, права, сеть, иконку не менять.
Не сканировать физические диски и не запрашивать пароль; discovery при открытии
экрана допустим. Не менять установленное приложение в /Applications.
Первоначально без публикации релиза, push или merge без нового запроса владельца.
